Cấu hình GitHub Token (Bắt buộc để lưu Public)

Cách sửa lỗi "Resource not accessible by personal access token":
Lỗi này xảy ra khi Token của bạn chưa được cấp quyền ghi đè (Write) vào kho mã nguồn. Bạn hãy làm theo sau:
1. Vào Cài đặt Token (Classic) của GitHub.
2. Bấm Generate new token (classic).
3. Trong phần Select scopes, kéo xuống và đánh dấu tích vào ô "repo" (Full control of private repositories).
4. Tạo Token, copy mã `ghp_...` dán vào ô bên trên và lưu lại.

Hướng dẫn lấy thông tin Strava:
1. Vào Strava API Settings và tạo một ứng dụng.
2. Lấy Client ID và Client Secret.
3. Lấy mã Refresh Token (Yêu cầu phải có quyền đọc dữ liệu nhóm - read_all).

1. Danh Sách Nhóm

Cách nhau 1 dòng trắng giữa các nhóm.
Ví dụ:
